# StreetSignal Platform 'Sticker Sheet'

Example files to design for StreetSignal's OSS tool 'platform'.

Currently the example files are available only in [Adobe XD](https://www.adobe.com/uk/products/xd.html). We're looking into making other file formats available for making design work for StreetSignal including other popular commercial design software as well as FOSS design software.

Adobe XD files of platform sticker sheet:  
[Sticker sheet files.zip](https://github.com/streetsignal/platform/files/3567091/Sticker.sheet.files.zip)
