# Localization and Translation

StreetSignal is translated into 34 localizations. Localization refers to a language in a specific location. Each language varies in "completeness" and there are 24 more localizations that still does not have any translations available. StreetSignal deployments with completed languages make it easier for the local regions to communicate with their users. With your help, we'd like to better serve them.

All the software translations for the StreetSignal platform and mobile applications are stored on [Github](https://github.com/streetsignal/StreetSignal-Localizations) and translation is done on [Transifex](https://www.transifex.com/). Transifex list for StreetSignal is [https://www.transifex.com/organization/streetsignal/dashboard](https://www.transifex.com/organization/streetsignal/dashboard), or for individual projects, see:
